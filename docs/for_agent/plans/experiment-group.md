## 三、各页面设计

### 页面1 通用投资框架（最简单，先做）
- **输入**：投资主题（文本，如"光通信"）
- **流程**：LLM 联网搜索 → 按框架 4 层顺序生成完整报告（提示词原文入库）
- **输出**：markdown 报告（4 层 + e-梯队仓位表：T0/T1/T2 梯队、e 衰减权重、归一化）
- **无外部数据**：纯 LLM（自搜索事实）；可加"批判层修正"二次生成

### 页面3 ec 泡沫预警（中等）
- **数据采集**（混合策略）：
  - 行情固化：EUR/JPY、USD/JPY、EUR/USD（quote 模块——需确认汇率支持；不支持则 LLM 搜索）
  - LLM 搜索：德日 10Y 利差、VIX、CFTC 空头、巴菲特指标（注入日期防幻觉）
- **指标计算（固化为纯函数 + 单测）**：
  - `B(t)`：已实现汇率变动 − 利差（周度）
  - `Ω`：五维度合成（汇率极端/空头拥挤/利差/反身性 CVAS/美股估值）
  - `CVAS`/`CCV`：波动率自强化 + 条件危机波动率
- **LLM**：数据缺口补全 + 战术研判（基于指标值 + 框架铁律）
- **输出**：指标仪表盘（B/Ω/CVAS/CCV 数值 + 预警灯）+ 研判 + 操作锚点表

### 页面2 BMPI（最复杂，最后做）
- **数据采集**：
  - 行情固化：S₁ 成分股股价（中国能建等）、S₂ 成分股、S₃ 成分股 PB（quote 模块）
  - LLM 搜索：国债 1Y/10Y、央行逆回购净投放、基建投资/房价/置换债进度等宏观
- **指标计算**：
  - `R`/`S_L`（利率环境/流动性）：公式固化（国债收益 + 逆回购 → 得分）
  - `S₁`/`S₂`：股价行情固化 + LLM 宏观补充
  - `S₃`：PB 行情固化 + LLM 宏观补充
  - `BMPI` 合成：动态三段权重（w₁+w₂+w₃=0.70，按阈值区间分配）
- **LLM**：宏观数据搜索 + 综合研判 + 数据质量标注（偏差提醒）
- **输出**：五指数得分卡 + BMPI 读数 + 仪表盘（红/黄/绿）+ 周度研判

## 四、数据与 LLM 分工原则（踩坑经验）

1. **公式固化为程序**（可测、稳定、省 LLM）：B/Ω/R/L/BMPI 合成等确定性计算绝不交 LLM
2. **行情走 quote 模块**（腾讯主源多源降级）；**宏观/政策/CFTC 走 LLM 搜索**
3. **LLM 输入注入当前日期**（防"本月"幻觉到训练月份）
4. **数据缺口**：沿用上期/标注"待核实"，不臆造（框架铁律，BMPI 对话已多次踩坑）
5. **输出结构化**：LLM 输出 JSON（指标+研判）用 robustJsonParse 容错
6. **缓存**：分析结果 KV 缓存（2 年）+ force 绕过；行情快照 5 分钟

## 六、风险

- **汇率数据源**：quote 模块是否覆盖外汇（EUR/JPY）——需探测；不支持则 fallback LLM 搜索或外部汇率 API
- **成分股清单**：BMPI 的 S₁/S₂/S₃ 成分股需从对话提取完整名单（含代码）
- **宏观数据时效**：LLM 搜索的数据日期标注（asOf），避免用旧值
- **规模控制**：BMPI 最重（多成分股行情 + 多宏观），拆步骤做，避免一次性大改
