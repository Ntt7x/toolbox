# 收益率计算口径（行业两种标准）

> 来源：用户提供行业标准公式（2026-08-24 确立）；应用于仓位管理 v2 的**组合净值曲线（NetValueChart）**「累计收益率」线，默认**净值收益率**，可切换**最大成本收益率**。
> 实现位置：`apps/web/src/tools/TradeV2Tool.tsx` → `NetValueChart`（retMode: `"nav" | "maxCost"`）。

## 一、净值收益率（默认）——时间加权收益率 TWR

**本质**：剔除资金进出影响，反映组合/基金本身的净值增长能力（基金行业评价标准）。

### 无资金进出

```
R = (NAV₁ − NAV₀) / NAV₀ = NAV₁/NAV₀ − 1
```

### 有资金进出（按时间加权，拆子区间）

将区间按每笔资金流入/流出拆成若干子区间，每段段内收益率：

```
rᵢ = NAVᵢ₊₁/NAVᵢ − 1
```

（有分红用复权净值）

总净值收益率（连乘）：

```
R_TWR = ∏ᵢ(1 + rᵢ) − 1
```

### 年化

```
R_年化 = (1 + R_TWR)^(365/d) − 1     （d = 区间天数）
```

### 本系统实现（日频简化）

- **日净值**：`NAVᵢ = 期初本金 p₀ + 市值ᵢ − 累计净投入ᵢ`（净投入 = Σ(买入−卖出)，资金进出已剔除）
- **曲线**：`净值收益率ᵢ = NAVᵢ/NAV₀ − 1`（区间起点净值归一 100%）
- 数学上 `∏(1+日收益率) − 1 = NAV末/NAV初 − 1`，与 TWR 等价。

## 二、最大成本收益率（可切换）——保守口径

**本质**：累计收益 ÷ 历史最大净投入成本，更接近投资者实际赚钱效率，且比"当前成本"更保守。

### 公式

```
最大成本收益率 = 累计收益 / 历史最大净投入成本
```

### 计算步骤

1. **现金流**：`I` 累计转入/申购，`O` 累计转出/赎回
2. **任一时点累计净投入**：`Cₜ = ΣI − ΣO`
3. **历史最大净投入成本**：`C_max = max(Cₜ)`（整个持有期间累计净投入曾达到的最大值）
4. **累计收益**：`累计收益 = 当前总资产 + ΣO − ΣI`
5. **最大成本收益率**：`R_MC = (当前总资产 + ΣO − ΣI) / C_max`

### 本系统实现（曲线逐点）

- **累计收益ᵢ**：`NAVᵢ − p₀`（= 累计盈亏，市值+现金口径）
- **分母**：`C_max = max(累计净投入序列)`（全程最大）
- **曲线**：`最大成本收益率ᵢ = (NAVᵢ − p₀) / C_max × 100%`

## 三、举例（用户提供）

期初投入 100 万 → 追加 50 万 → 转出 30 万 → 期末总资产 160 万：

- 累计投入 150 万，累计转出 30 万
- 累计收益 = 160 + 30 − 150 = **40 万**
- C_max = 150 万
- 最大成本收益率 = 40/150 = **26.67%**

## 四、区别与用途

| 口径 | 计算核心 | 主要用途 |
|---|---|---|
| 净值收益率 | 单位净值增长，时间加权 | 评价组合管理能力，便于比较 |
| 最大成本收益率 | 累计收益 ÷ 最大净投入成本 | 反映持有人实际收益效率，更保守 |

默认展示净值收益率；大额转入/转出时可切换最大成本收益率，更贴近实际盈亏感受。
