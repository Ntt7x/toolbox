# 2026-08-26-03 · 兼容层全清除（data-infra 唯一任务链路）+ 改造彻底性原则

## 背景
data-infra 统一任务链路落地后，前端仍残留一批 AsyncTaskResult 兼容方法（core/tasks 时代的产物）。用户确立新原则："改就要改彻底，先进就全部先进，不要妥协，妥协反而混乱"，本分支执行兼容层全清除。

- **apps/web/src/api.ts**：删除 6 个 AsyncTaskResult 兼容方法（taskStatus / taskHistoryList / taskHistoryEntry / watchlistAppendTaskStatus / watchlistFundamentalTaskStatus / watchlistImportTaskStatus）；新增 `dataInfraTask(taskId)` 原生详情 + `dataInfraResult<T>(taskId)` + `dataInfraTasks()`；`TaskCreateResult<T>={ok, taskId?, result?, message?, status?}`；`export const api`

- **apps/web/src/settings/AgentSessions.tsx**：waitTask → `dataInfraTask` + `!task.ok || !task.taskId` 守卫
- **apps/web/src/tools/WatchlistTool.tsx**：3 处手动轮询改 `dataInfraTask` 详情直读（appendChat preview 从 `result.stocks` 取）

- **docs/for_agent/dev.md**：⛔ 教训 #10（改要改彻底）+ §5.0 改造原则（不留兼容层/双轨/过渡态，妥协反而混乱）

## 教训
- 大文件机械删除会破坏多行方法块（api.ts 被删坏 3 次）——先全量读再精确删
