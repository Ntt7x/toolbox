## 提示词固化（分享对话推导，程序忠实实现）
- 输入 5 字段：当前价 P / 上止盈 TP / 下止损 SL / 主观胜率 p（0~1 或 %）/ 可用金额 A
- b = (TP-P)/(P-SL)；expected_edge = p*b-(1-p)；f_raw = edge/b
- 方案 r = f_raw/4、f_raw/3、f_raw/2、f_raw：shares = floor(A*r/P/100)*100；cash = shares*P；pct = cash/A
- 分支：f_raw≤0 无正期望；全零无有效仓位；错误信息原文（止盈止损异常/金额不足等）
- 示例验算（P30/TP39/SL24/p75%/A50000）：b=1.5、edge=87.5%、fRaw=58.33%，方案 6000/9000/12000/27000 → 与对话完全一致
