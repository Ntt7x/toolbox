# 2026-08-05-07 — 提示词统一整合到「本地设置数据」

**会话主题**：把所有提示词（cb-rate system/user、grid-plan）统一存储到「本地设置数据」
（SQLite `settings:prompt.*`），页面展示与服务端使用走同一条数据链路。

## 完成的功能

1. **core/prompts.ts（新，核心公共模块）**：提示词注册表——默认值集中 seed
   （cb-rate.system 占位符模板、cb-rate.user 模板、grid-plan.system 全文），运行时读写
   settingsStore（`settings:prompt.*`），提供 getPromptTemplate / listPrompts /
   getPromptDetail（template + 默认参数 rendered 预览）/ updatePrompt / resetPrompt。
2. **prompts API**（core/routes.ts）：`GET /api/prompts`（列表）、`GET /api/prompts/:id`
   （template+rendered）、`PUT /api/prompts/:id`（更新）、`POST /api/prompts/:id/reset`（重置）。
3. **cbRate service 改造**：buildSystemPrompt/buildUserPrompt 改为从
   `getPromptTemplate("cb-rate.system"/"cb-rate.user")` 读模板做占位符替换；
   搜索注记常量（联网/知识）从 prompts.ts 导出共用（单一来源）。
4. **web 页面改造**：CbRateTool / GridPlanTool 的「查看程序性提示词」改为挂载时
   `api.promptDetail(id)` 拉取 rendered 展示/复制（不再 import 本地常量）。
5. **删除**：shared 的 CB_RATE_* 提示词常量、web `gridPrompt.ts`（全文迁入 prompts 注册表）。
