# 2026-08-27 · 聚合分组回归一般分组底层架构

## 背景
仓位管理页（trade-v2）此前实现"聚合分组"时生搬硬套旧的"全部组合"逻辑：独立的 `buildAggregateAnalysis`/`TradeV2AggregateAnalysis`/global 渲染分支/分组贡献表，与"聚合分组 = 一般分组"的底层思路冲突，且遗留大量 global 状态（多次引发 `global is not defined` 运行时崩溃）。

## 本次改动（main 815eab9，fast-forward 自 4959e1e）
- **服务端**
  - `groupAnalysis` 统一：聚合分组与基础分组同走 `analyzeGroup`（`getGroupEntries` 按 `aggSources` 派生来源条目并集 → analyzeGroup 即组合分析），删除聚合专用返回结构；详情接口不再返回派生 entries（前端本地过滤）
  - `buildAggregateAnalysis` 保留为通用纯函数（测试覆盖），注释明确"聚合分组业务路径已统一走 analyzeGroup"
  - `store.ts`：`createGroup/updateGroup` 支持 `aggSources`（透传 isPaper/aggSources）
- **前端（TradeV2Tool）**
  - 彻底删除 `global/globalGroup/aggEntries` 三 state、组合视图 tab（analysis-global）、组合整体卡、分组贡献表、pie/bar/globalLine 图表、`srcGroups` 等"全部组合"遗产（约 200 行）
  - 聚合分组与基础分组**同一套 detail 渲染**（收益/仓位/流水/日度汇总/下钻）
  - **聚合分组专属"🧩 组合分析" tab**：组合整体卡（来源分组数/合并盈亏/集中度）+ 分组贡献表（来源分组，点击跳转）+ 分组市值占比/盈亏对比 + 组合净值曲线（合并视图）——数据 = srcGroups（来源过滤）+ analysis（派生）
  - 聚合分组差异化仅剩本质项：流水 = 来源条目过滤、只读不可记账、设置 tab 可编辑来源、无信息/实虚标签、空状态提示"来源分组暂无交易"
  - 修复 `global` 残留 4 处（deps 数组/analysis-global tab 按钮/过时注释——运行时 ReferenceError 根因）
- **shared**：`TradeV2GroupDetailResult` 删 `entries`；`TradeV2AggregateAnalysis` 保留（服务端 compute 用）；`TradeV2Group` 含 `isPaper/aggSources`
- 附带：favicon（`favicon.svg` + index.html 引入）

## 验证
- typecheck（server+web）全绿；tradeV2 39/39 + metrics 9/9

- 浏览器实测：聚合分组显示"🧩 组合分析" tab，贡献表/净值曲线/市值占比渲染正常、无报错；基础分组不显示
