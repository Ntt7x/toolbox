# 2026-08-05-21 — 新增「专题自选股」页面（交易分组）

**会话主题**：开发"交易"分组的"专题自选股"页面：新建专题、专题内收录
（入选个股 + 入选理由）、个股详情（标准行情工具取基本信息 + LLM 财报分析）。
参考用户提供的 6 个示例专题（AI 硬件/AI 应用/商业航天/债务扩张/水利开支/通胀消费）理解结构。

## 完成的功能

1. **数据层**（features/watchlist/store.ts，Key-结构化 Value 持久化）：
   - 每个专题一个 KV 文档 `watchlist:<id>` → { id, name, createdAt, updatedAt, stocks[] }
   - CRUD：listTopics / createTopic / getTopic / updateTopic（改名/增删个股原子提交）/ deleteTopic
   - 数据源注册：`watchlist:`（自选数据）+ `watchlist:fundamental:`（分析数据）
2. **个股信息**：
   - 名称解析：复用 core/quote（标准行情工具）`GET /tools/watchlist/resolve?code=`
   - LLM 财报分析：`POST /tools/watchlist/:id/fundamental?code=&force=` 后台任务
     （watchlist.fundamental 提示词，默认联网搜索，robustJsonParse 容错，
     KV 缓存 TTL 2 年，force 绕过）
3. **契约**：WatchlistTopic/Stock/Summary + CRUD 请求响应 + FundamentalResult
4. **前端 WatchlistTool**：左侧专题列表（新建/选中/删除），右侧专题详情
   （改名、添加个股[代码+名称自动解析+理由]、个股表、移除、财报分析卡片[联网/缓存标注]）

## 关键教训

- **Hono 路由顺序**：静态路由（`/resolve`）必须注册在参数路由（`/:id`）之前，
  否则被当作 id 吞掉（实测返回"专题不存在"）
