# 2026-08-07 58 · 项目架构依赖图（自动生成 + 交互展示页）

## 需求
维护跟踪项目逻辑的依赖图（SVG/图谱工具），dev.md 记录；后台管理新增静态页展示（前端知识图谱交互）；后续开发跟进更新。

## 实现
### 1. 服务端自动生成（core/dependencyGraph.ts）
- 运行时扫描 `features/*/index.ts` + 同目录业务文件 + `core/*.ts` 的相对 import（`../../core/xxx.js` / `./xxx.js`），
  生成 `{nodes, edges}`——**新增/修改模块依赖自动反映，无需手工维护图结构**
- 手工补充映射表：`NODE_NAMES`（中文名）、`NODE_DESC`（关键模块说明：llm 三模式/知识库/数据库）、
  `EXTERNAL_EDGES`（DeepSeek API / Reasonix Agent / SQLite .file / MCP kb）、`LLM_MODE_EDGES`（业务→三模式）
- 路由 `GET /api/dependency-graph`（core/routes.ts）

### 2. 前端交互展示（settings/ArchGraph.tsx + ECharts 6 graph 力导向）
- 节点四色分类：业务模块(蓝)/公共模块(紫)/外部系统(红)/数据层(绿)
- 交互：拖拽节点、滚轮缩放、hover 高亮邻接、**点击节点右侧详情面板**（说明/类型/入边出边列表）
- 边带标签（依赖 / LLM 模式 / ACP 会话 / API 调用 / 数据读写）
- 「⟳ 重新生成」刷新、图例、生成时间
- 菜单：后台管理 →「架构图」`/settings/arch-graph`；api.dependencyGraph

### 3. dev.md §7.2 规范
- 自动生成机制、展示入口、手工映射表同步清单（NODE_NAMES/NODE_DESC/EXTERNAL_EDGES/LLM_MODE_EDGES）、
  单向依赖架构约束（features→core→外部）、验证方式
