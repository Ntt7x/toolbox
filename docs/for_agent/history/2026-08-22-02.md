**2. 标的市场波动率流水线（数据工程模块化）**
- 用户指出方向错误：波动率是**市场/标的客观属性**（价格波动），与用户交易无关；初版误用"持仓市值序列"（含资金进出）算波动。
- **core/volatility.ts**（公共·纯函数，零 I/O）：滑动窗口增量（sum/sumsq O(1)）+ 历史σ分级；**8 个单测**（窗口/增量一致性/幂等/高低极波边界）
- **core/volatilityStore.ts**（公共·副作用）：KV 持久化 `quote:v:<code>` + 行情日K；首次 250 日初始化、每日 O(1) 增量、同日幂等；已注册数据源
- **金融口径**：年化波动 = 日收益率样本标准差 × √252（近 60 交易日）；分级用**标准差 z-score**（相对自身历史分布）：z<0 低波 / 0~1 中波 / 1~1.5 高波 / >1.5 极波
- **features/tradeV2/services.ts**：分组分析后批量附加 `positions.volatility/volLevel`

**3. 信息-风险提醒（用户确认风险语义）**
- 仓位明细（分组视图）：点名高波/极波标的
- 提交交易单（单标的提醒）
- **风险语义**：无信息策略高波 = 环境错配（规律被冲散）→ **建议暂停交易**；有信息策略高波 = 信息优势仍在只是信噪比稀释 → **建议降仓（无需清仓）**

**4. 经验沉淀**：`domains/data-engineering.md` §7「波动率流水线（增量状态机模式）」——纯/副作用分离、KV 持久化、z-score 分级、与交易解耦、复用指引
