# 2026-08-05-04 — 全库一致性修复与轻度重构

**会话主题**：对全库做一次一致性修复（4 个并行只读审查 + 集中修复），消除多次迭代遗留的不一致/死代码/缺陷。

## A 组：真实缺陷修复

1. **SSE 心跳定时器泄漏**（`core/sse.ts`）：任务 done 后 Hono `stream.close()` 不触发 onAbort，心跳每 15s 空转——重构为统一 `cleanup()`（off + clearInterval），终态/竞态/abort 三路径共用。
2. **useAsyncTask 恢复后取消失效**（`hooks/useAsyncTask.ts`）：mount 恢复任务时补 `setTaskId(tid)`——此前 taskId 为 null，恢复后的任务点「停止分析」无法通知服务端取消。
3. **CbRateTool loading 恒假**：`run()` 补 `setLoading(true)`。
4. **CbRateTool result 断言掩盖数据流**：去掉 `as CbRateResult` 断言与不可达的 `result && !result.ok` 死分支；提交失败不再 `task.reset()`（保留历史结果，仅提示错误）。
5. **api.ts 错误详情丢失**：重写为统一 `request()` 核心——非 2xx 优先抛 body.message；`localDelete` 修复（无错误处理）；新增 `errMsg(e)` helper；`llmSettings/shareExtract/localUpdate` 复用共享契约类型（反向收敛，消除 3 个死契约类型）。
6. **gridPlan 错误结构**：删 422 特例（业务失败统一 400）、删不可达 format 特判、更新过时对话式错误文案。
7. **过时文案**：LlmSettings「保存到 .env」→「SQLite 本地设置库」；GridPlanTool 误导性「可附带文字备注」（照做必 400）→ 明确三个数字；kvStore 头注释（quote: 前缀不存在）→ 真实前缀；tasks.ts 注释；LlmStatusResponse.model 等契约注释校准。

## B 组：死代码清理

- 删除无引用导出：`kvList`、`matchRegisteredPrefix`（+localData 死导入）、`hasSetting`/`listSettings`、`createTable`/`dropTable`/`insertRow`/`updateRows`（tableStore 保留查询/删除/计数）、`isTaskResult`、`REASONER_MODEL`、`GridPlanErrorResponse` 死导入、`parseSecCode` 改私有、compute 死条件 `M !== L`（恒真）与无实义注释。
