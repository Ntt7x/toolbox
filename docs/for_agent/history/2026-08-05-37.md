# 2026-08-05 37 · 菜单栏增强（分组折叠 + 编辑模式拖拽排序）

## 需求
1. 分组可以折叠收起
2. 菜单可进入编辑模式，编辑模式下拖动菜单顺序，顺序数据由服务端 settings 数据支持

## 实现（apps/web/src/App.tsx 重构）
- **分组折叠**：分组标题（▾/▸ + label + 条目数）点击折叠/展开；状态存 localStorage `menu.collapsed`（UI 偏好，不进服务端）；"其他"分组同样支持
- **编辑模式**：
  - 侧栏「✏️ 编辑菜单（拖动排序）」进入；显示「💾 保存顺序 / 取消」+ 提示文字
  - 组内条目 HTML5 拖拽（⠿ 把手 + 序号 + 拖起高亮），组内跨序重排（draftOrder 草稿）
  - 保存 → PUT `/api/data/local/entry`（source=settings:&key=settings:menu.order）→ 服务端设置持久化
- **顺序数据**：`{ [分组label]: [key...] }`，key=工具 id 或设置页 path；resolveGroupItems 按用户顺序渲染、未列出的补末尾；无配置回默认
- 折叠状态仅影响 UI；编辑模式下不折叠（保证拖拽可见）
