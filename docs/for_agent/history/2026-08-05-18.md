# 2026-08-05-18 — 修复余额曲线绘制问题（断档假连接/面积跨 null/标签重叠）

**会话主题**：修复 ECharts 余额曲线绘制问题。

## 问题与修复

1. **断档假连接（主问题）**：单 series + null 占位 + connectNulls:false 只能断折线，
   **areaStyle 面积仍会跨 null 连接**——2025-04~2026-02 缺失段出现假直线 + 大块渐变填充，
   视觉上像真实数据。修复：`splitSegments` 按连续月份拆分为**独立 series**，
   每段折线与面积都真实断开（峰谷标注只放在最后一段）。
2. **x 轴标签拥挤**：23 个月份标签全挤。修复：`hideOverlap: true` + time 轴自动抽稀。
3. **tooltip 显示时间戳**：valueFormatter 千分位、日期轴格式化 YYYY-MM。
