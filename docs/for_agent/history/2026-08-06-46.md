## 修复的缺陷（6 处）
1. **rpc 定时器泄漏**（reasonix）：超时 setTimeout 从不清理，每个 rpc 遗留最长 90s 定时器保持事件循环 → pending 改存 `{resolve, timer}` 元组，响应/退出/超时统一 clearTimeout
2. **spawn 错误未监听 → uncaughtException**（reasonix）：spawn 对不存在二进制是异步 'error' 事件，startAcp 无监听 → 改：spawn 前 existsSync 预检（同步抛→rpc catch）+ child.on('error') 兜底（拒绝 pending + 重建）
3. **归档 close 使 list 崩溃**（reasonix）：listReasonixSessions 归档态 rpc 同步 throw（二进制缺失时）→ rpc 内部 try/catch getAcp 转 error 返回，所有调用方免 try
4. **ACP 崩溃无法自动恢复**（reasonix）：sessionGone 匹配未含进程退出 → 正则补 `进程已退出|exited`；doAsk 内 getAcp 同步抛兜底
5. **双重 load**（chatSession）：restoreArchivedSession 恒非 null，`?? loadSession` 死代码 → 删除；compactSession 支持传已加载会话避免重复 load
6. **ttlMs 接口歧义**（chatSession）：两级生命周期固定（30/360 天）后 ttlMs 可配置性无意义 → 移除 opts.ttlMs；损坏 JSON 防御（reasonix list / kvListAll）
