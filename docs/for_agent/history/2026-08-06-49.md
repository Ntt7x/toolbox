# 2026-08-06 49 · LLM 用量按业务场景切面区分改造

## 需求
用户反馈：`it.reasonix` / `it.chatsession` 等 module 对用户无业务场景意义。梳理场景并妥善设计，按业务场景区分 LLM 用量。

## 场景梳理（module 全景）
| 场景 | module | 说明 |
|---|---|---|
| **business 业务** | cb-rate / treasury-fx / reverse-repo.daily / reverse-repo.monthly-update / watchlist.fundamental / watchlist.import | 页面业务调用 |
| **system 系统** | llm.test / llm.chat | 设置页连接测试/对话验证 |
| **test 测试** | it.* / test.*（it.chatsession、it.reasonix 等） | 集成测试/单测真实调用 |

## 设计
- shared：`LlmUsageScene = "business" | "system" | "test"`；`LlmUsageSummary` total 增 `byScene`；byModule/byDay 条目增 `scene`
- core/llm.ts：
  - `recordLlmUsage(..., mode, scene?)`：**切面显式标注** scene（缺省按 module 推断兜底）
  - `sceneOfModule(module)`：`it.`/`it:`/`test.`/`test:` 前缀 → test；`llm.test`/`llm.chat` → system；其余 business（兼容 `.`/`:` 分隔）
  - UsageEntry 存 scene；旧数据（无 scene）聚合时按 module 推断（兼容历史）
  - 聚合：total.byScene（中文 label）+ byModule/byDay 带 scene
- 前端 LlmSettings："按模块"改为**按场景分组**（`<details>`：业务场景默认展开；⚙️系统工具 / 🧪测试 折叠展示，组头含调用次数）

## 验证
- 单测 49/49（新增场景聚合 + sceneOfModule 规则用例；修复断言字段 promptTokens→totalTokens）
- API 实测：byScene = business 10 次（59% 命中）/ test 10 次（99.5% 命中——集成测试会话缓存验证）；byModule 场景标注正确（it.reasonix[test] / treasury-fx[business] / reverse-repo.daily[business]）
