## chatSession 扩展（支持业务接入）
- `CreateSessionOptions.id?`：业务确定性 id，**幂等复用**（system 相同保留历史刷新活跃；system 变更重建作废）+ 非法 id 校验
- `temperature?`：固定温度（会话内不变，保持前缀语义）
- `chatSessionAsk(id, msg, { signal })`：**signal 透传**（任务取消中断 LLM）
