# 2026-09-06-01 · 自选股数据链路引入 Effect-TS + RxJS 重构

## 目标
把自选股行情数据链路从「Promise + 手写 mapLimit + 裸 fetch + 各面板各自轮询」重构为
**Effect-TS（取数编排/类型化错误/结构化并发）+ RxJS（事件流编排/多播/单飞）**，并沉淀经验。

## 分工铁律
- **取数本身**（超时/重试/错误/并发/缓存）→ Effect（`core/effect/*`）
- **事件流编排**（何时取、取完怎么分发、多播/退订/重连）→ RxJS（`features/watchlist/stream/*`）
- 边界：RxJS 流只调 pipeline 的 Effect，**自己不 fetch**；取数内核一律经 `core/effect/http` 的 `requestX`，
  禁止裸 `fetch` + `AbortSignal.timeout` 散落 feature。

## 落地内容
### 服务端（`apps/server`）
- `core/effect/` 新增内核：`errors.ts`（类型化 `FetchError` + `describeError` 一处出中文文案）、
  `runtime.ts`（runEffect / runEffectOrMessage / interruptOn）、`http.ts`（requestText/Json/Buffer，
  超时真中断 + 指数退避重试，仅超时/网络/5xx/429 重试）、`concurrency.ts`（allOrdered 保序并发+
  结构化中断 / allSettled 逐项容错转 note）。
- `core/quote.ts`、`core/kline.ts`：三源 failover + K线/分时全部改 Effect 实现；`concurrency.ts` 的 `mapLimit` 委托 Effect。
- `features/watchlist/pipeline/`：`lineage.ts`（血缘累加器，统一 sources/fromCache/degraded/caveats 出口）、
  `sources.ts`（数据源 Effect 封装）、`rows.ts`（标的列表装配，单次取数 → rows + pctByCode 复用，修掉 `/tags` 二次取数）、
  `track.ts`（快照与日K 并行 + 周期聚合）、`index.ts`（统一出口）。
- `features/watchlist/stream/`：`quoteStream.ts`（共享行情流：多播/单飞/限速/无人即停）、
  `alertWatcher.ts`（挂在行情流上的提醒判定消费者，页面没开也能落库）、`index.ts` 统一出口。
- `index.ts` 路由接入：新增 SSE 端点 `/stream` + 手动刷新 `/stream/refresh`；`/tags`、`/items` 改为单次取数复用；
  `/quotes` 批量走 `quoteSnapshots` Effect；`register` 启动提醒消费者单例。

### 前端（`apps/web`）
- `lib/quoteStream.ts`（RxJS 行情流客户端：共享连接 + 指数退避重连）、`hooks/useQuoteStream.ts`（`useQuoteStream` + `mergeLiveQuotes`）、
  `hooks/useAsyncData.ts`（switchMap 语义，消除面板加载竞态）。
- `WatchlistTool.tsx` 接 SSE 实时行情；`ItemList/TrackPanel/AlertsPanel/DeepDivePanel` 改用 `useAsyncData`/`useQuoteStream`
  消除加载竞态与重复轮询。

## 验证
- L0 `toolbox typecheck`：server + web 全过。
- L1 `toolbox test`：全量服务端单测 pass（含新增 `core/effect` 13 例 + 原 watchlist 16 例）。
- L2 接口实测：dev 环境跑通 →
  - `GET /tags`、`GET /items` 返回 `meta`（血缘）。
  - `GET /stream?codes=sh600519` 返回 `text/event-stream`，每 15s 一帧真实快照（source:tencent）。
  - `POST /stream/refresh` 立即刷新成功。

## 收益
- `/tags` 首屏取数从两次全量快照 → 单次（开销减半）。
- 多面板共享一条取数链路（不再 N 倍 QPS），刷新节奏一致。
- 结构化并发：批量取数任一源失败即中断兄弟任务，无悬空请求。
- 提醒判定从「被动（开页才触发）」变「常驻消费（按流节奏落库）」。
