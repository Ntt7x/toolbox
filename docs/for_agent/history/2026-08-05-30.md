# 2026-08-05-30 — 本地数据管理优化（痛点梳理：未标记治理/搜索/分页/清空/格式化）

**会话主题**：数据越来越多、越来越复杂，梳理数据痛点，优化"本地数据管理"页面并强化功能。

## 痛点梳理（实测数据）

- **64 条"未标记"**：行情快照缓存 `quote:s:` 未注册数据源，全部落入未标记聚合项，
  无法按来源管理（最痛点）
- 大源（cbRate 18 条等）无搜索/分页，浏览困难
- 缓存类源无法一键清空
- 详情 KV 值无格式化展示

## 完成的功能

1. **未标记治理**：core/quote.ts 注册数据源 `quote:s:`（行情缓存，tag 分析数据）→
   **未标记从 64 条 → 0 条**
2. **entries 增强**（服务端）：
   - `search` 参数（key/值包含匹配）
   - `limit`（默认 200 上限 500）+ `offset` 分页（返回 offset/limit/total）
   - 批量清空：`DELETE /api/data/local/entries?source=`（key 归属校验）
3. **前端 LocalData 重构**：
   - 源列表按 **tag 分组**（设置/自选/分析缓存/分析数据/存量/运行状态/备忘录/未标记 + 各组合计）
   - 条目列表：**搜索框**（key/值包含）+ **加载更多分页** + 缓存类源 **🗑 清空按钮**（强确认）
   - 详情：JSON **格式化展示**（深色代码块）+「✏️ 编辑」切换（保存时 JSON 校验）
   - 契约：LocalDataListResponse 加 offset/limit；api.localEntries 支持 search/limit/offset

## 验证
