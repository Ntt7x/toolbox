# 2026-08-05-11 — 新增交易页面「国债汇率分析」

**会话主题**：阅读 DeepSeek 分享对话（daudtgz8dh3zyi9a4u，46 条消息 37K tokens），
理解「人民币短波段研判框架：汇率套利+债券信号」，整理提示词并实现第三个交易功能页。

## 需求提取（从对话）

- 输入：近 N 个交易日（1~10）的 USDJPY、USDCNY（在岸/中间价）、JP10Y、CN10Y
- 核心框架：UJ/UC/0 六种排序 → 资金流向 → 三阶段（美日/日中/中美）；
  债券「发令枪」：UC<UJ<0 且 CN10Y>JP10Y 才确认主升浪（否则日中延长）；
  嵌套级别：大级别 UJ<0<UC / 小级别 UJ<UC<0 / 中级别 UC<0<UJ；
  防幻觉硬约束：无 CN10Y>JP10Y 严禁输出"主升浪"
- 输出：数据速览表 + 框架判定 + 操作结论（JSON）

## 完成的功能

1. **提示词**：treasury-fx.system（完整框架，3329 字，含排序表/阶段/发令枪/级别/工作流/
   历史复盘/防幻觉）与 treasury-fx.user（模板 {date} {days}）入 prompts 注册表（可编辑）。
2. **core/jsonParse.ts**：robustJsonParse/fixJsonQuotes/extractOuterJson 从 cbRate 提到
   core 公共模块，cbRate 与 treasuryFx 共用（单测改 import 后仍 20/20）。
3. **shared 契约**：TreasuryFxRequest/Response/Row（days/search/useCache、asOf/rows/
   summary/conclusion/dataMode/knowledgeCutoff/fromCache/raw）。
4. **features/treasuryFx**：meta + POST /api/tools/treasury-fx（后台任务+缓存 TTL 24h +
   v1 key）+ GET task 轮询 + 数据源注册；service 仿 cbRate（prompts 读模板 + chat(search) +
   robustJsonParse + rows 规范化）。
5. **前端**：TreasuryFxTool 页面（窗口天数 1/3/5/10 + 搜索/缓存开关 + 停止按钮 +
   提示词查看/复制/Chat + 结果速览表/判定/结论/raw）；api.ts 两方法；交易菜单注册。
6. **修复**：服务端 8787 曾因 tsx watch 崩溃（历史遗留），已重启为独立后台进程；
