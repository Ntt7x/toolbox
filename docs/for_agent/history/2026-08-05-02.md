## 完成的功能

1. **防幻觉（核心缺陷）**：知识模式（search:false）提示词重写——注入今天日期 + 明确"训练知识截止约 2025 年中、严禁编造今天之后的会议与决策、asOf 用知识最新日期"；响应新增 `dataMode: search|knowledge` + `knowledgeCutoff`。实测旧版编造"2026年7月维持0.50%（中村将否决）"（中村将已离任=幻觉），新版返回真实知识（BOJ 0.50% 截至 2025-06、asOf=2025-06-30）。

4. **任务超时终态保护（卡死修复）**：`core/tasks.ts` fn 在超时/取消后迟到返回不再覆盖 error/cancelled 终态（实测 DeepSeek search 对 abort 无响应时正常返回会覆盖 error → 显示 done）。

6. **单测体系**：`features/cbRate/cbRate.test.ts`（14 项）+ `core/tasks.test.ts`（6 项），node:test + tsx 运行，全绿。
