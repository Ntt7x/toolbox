# 2026-08-05-19 — 余额曲线连续化（高级加工：模型推算补全缺失段 + 口径纠正）

**会话主题**：用户反馈"曲线在中间断开"仍未解决——断档因 2025-04~2026-02 无权威
累计净投放。授权"高级加工数据和持久化"，实现连续曲线。

## 关键发现（口径陷阱）

- 用户第一版"月末余额"实为**累计投放**（Σ投放）：2025-02=58000 = 累计投放验证✓
- 第三版"累计净投放"（含到期）才是**真实存量余额**（2026-07 6.2万亿≈对话"6.3万亿"✓）
- 原 monthlyData 将 2025-02/03 的累计投放值（58000/66000）当 cumulativeNet——**口径混用**，
  与 2026 锚点（净投放口径）断层，是曲线"断开/怪异"的根因之一

## 完成的功能

1. **口径纠正**：2025-02/03 cumulativeNet 改 null（月度表该列显示"—"），note 注明无权威值
2. **模型推算 `deriveBalanceSeries`**（service.ts，实时派生不持久化）：
   - 逐月流量：投放 = 逐笔操作按投放月；到期 = 投放日 + 3/6 自然月（y×12+m 进位，无 setMonth 溢出）
   - 权威锚点（cumulativeNet 非空）优先并**重置推算基线**（防漂移累积）
   - 缺失月份（2025-02~2026-02 共 13 个月）用推算值，`estimated:true`
   - 输出截断到最新数据月（不展示未来推算）
3. **shared**：series 项加 `estimated?: boolean`
4. **前端 BalanceChart**：单 series 连续曲线（不再拆段）；推算点空心灰点、
   权威点实心蓝点；tooltip 标注「(模型推算)」；去掉峰谷 markPoint（推算点会误导）
