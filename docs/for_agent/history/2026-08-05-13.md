# 2026-08-05-13 — 新增交易页面「逆回购余额」（存量权威数据 + 增量 LLM）

**会话主题**：阅读 DeepSeek 分享对话（bhic7y47khkjggjoz9，26 条）理解买断式逆回购
余额跟踪需求；用户直接提供 2024.10-2026.8 权威月度数据，存量部分改为静态种子数据。

## 需求提取（从对话）

- 存量：买断式逆回购（2024.10 启用，3M/6M）自启用以来每月操作 → 流水表 + 余额曲线
- 增量：每日变动量探查 + 当月变动量说明
- 用户方向：余额作为流动性信号（≥7.5 万亿阈值判断风格）

## 完成的功能

1. **存量（权威种子）**：`features/reverseRepo/monthlyData.ts` 固化用户提供的
   2024.10-2026.8 月度表（22 行：月份/操作总量/3M/6M/月末余额/备注），
   `GET /api/tools/reverse-repo/monthly` 直接返回（月度表 + 21 点余额序列，零 LLM 开销）；
   2026-05 余额暂缺、2026-08 进行中按 null 处理。
2. **增量（LLM）**：`POST /api/tools/reverse-repo/daily` 后台任务（缓存 TTL 30 分钟）+
   轮询路由；提示词 `reverse-repo.daily` 入注册表（区分买断式/7天期、当月说明、currentBalance）。
3. **前端 ReverseRepoTool**：月度流水表 + 存量余额曲线（SVG 折线，无依赖）+
   每日变动探查（当日/最近变动表 + 当月说明 + 存量徽章）+ 提示词查看/复制/Chat。
4. **调试清理**：tasks.ts 临时日志、index.ts debug-timeout 路由、reverseRepo 临时 timeoutMs
   全部移除；多进程残留（EADDRINUSE）已清理，恢复 pnpm dev（vite + tsx watch）。
