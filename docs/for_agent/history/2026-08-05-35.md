# 2026-08-05 35 · 书籍下载（zlib 搜索 + 浏览器下载）

## 需求
小工具分组新增「书籍下载」：输入书名（模糊搜索）→ 后台到 zlib 搜索 → 启动浏览器下载。

## 调研结论（zlib 技术约束）
- zlib 主域名本机**直连超时（被墙）**，必须经用户本机代理 `http://127.0.0.1:10808`（git 同款代理）→ 服务端用 undici `ProxyAgent` 走代理
- 旧接口已废弃：`fundgz`（无关）、`api.z-library.se`（域名待售）、`z-library.bz/dapi`（404）
- **可用内部 API**：`POST {base}/api/search`，form：`q/page/limit/order`（order=popular）
  - 返回 `{success:1, books:[{id,title,author,year,publisher,language,extension,filesize,filesizeString,md5,hash,cover,href,dl,readOnlineUrl}], pagination?}`
  - `pagination` 常为空 → total 提取不到时前端显示"返回 N 条"
  - **匿名搜索偶发 429**（限流，同一出口 IP 第二次调用成功）→ 友好提示 + 浏览器直接搜兜底
  - 新 UI 搜索页为 JS 渲染骨架（skeleton），HTML 解析不可行；`/s/?q=` 页无书籍实例
- **下载机制**：`dl` 字段相对路径（如 `/dl/M9D2q7MOKy`）→ 前端 `window.open(base+dl)`，浏览器（登录态 + 系统代理）完成下载

## 修复记录 2（下载 404）
- 用户反馈"下载页 404"：实测 `GET {base}/dl/<hash>` 匿名永远返回 **Page Not Found**（HTTP 200 包装）——zlib 下载**强制登录会话**，匿名搜索响应里的 dl 短链无效（即使搜索后立即请求也 404；md5 版同理）。href 详情页域 z-library.im 当前 503、z-lib.sk 有 Cloudflare 挑战、z-library.bz 上 /book/ 路径 404——各域不稳定。
- **下载策略改为**：前端「⬇ 打开下载」→ `window.open({zlibBase}/s/?q={书名})` 浏览器打开该书搜索结果页，登录态下点书进详情下载。页面说明横幅更新（③ 下载需登录）。
- **结论（zlib 下载机制）**：搜索可匿名（有 429 限额）；下载必须浏览器登录会话。服务端无法匿名下载，也不应绕过登录。
