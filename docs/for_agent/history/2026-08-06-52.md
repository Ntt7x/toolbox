# 2026-08-06 52 · 「医疗经验」→「医学知识库」（知识库公共模块首个业务落地）

## 需求
把「医疗经验」页面改造为「医学知识库」：用户输入"知识"（目前仅有 Chat 链接），并可对知识库问答。

## 实现
### core/knowledge.ts（公共模块增强，支撑业务实例化）
- `kbImportFromChat(url, { instance? })`：导入时给 key 加实例前缀（medical.<原始key>），实现特定业务知识库
- `kbAsk(question, { instance? })`：检索限定实例前缀（medical.），问答不跨实例串扰

### features/rehab（业务层）
- `registerMedicalKb(app)` 路由（medical 实例，基于 core/knowledge）：
  - `POST /api/tools/medical-kb/import {url}`（后台任务，module medical-kb.import，可读名称）
  - `GET /api/tools/medical-kb`（列表）
  - `DELETE /api/tools/medical-kb/:key`（key 归属校验）
  - `POST /api/tools/medical-kb/ask {question}`（后台任务，module medical-kb.ask）
- 数据源注册 `medical.`（本地数据管理可见）
- meta 名称「医疗经验」→「医学知识库」

### 通用任务状态（core/sse.ts + api.ts）
- 新增 `GET /api/tasks/:taskId`（getTask 实时状态，轮询兜底）——注册在 /history 静态路由**之后**（避免参数路由吞静态，dev.md 已记录此坑）
- `api.taskStatus<T>(taskId)` 前端通用方法

### 前端
- 新页面 `MedicalKbTool.tsx`：知识导入（Chat 链接 + 后台任务状态）、知识问答（答案 + 命中条目）、知识列表（key/value/来源/时间 + 删除）
- `RehabMedicalTool.tsx` 改为导出 MedicalKbTool（路由不变 /tools/rehab-medical）
- 旧 rehab:medical 笔记数据保留（本地数据管理可见，不删）
