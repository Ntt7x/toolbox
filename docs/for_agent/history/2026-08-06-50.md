### 2. 菜单编辑模式修复（agent-sessions 不可拖）
- **根因**：`settings:menu.order` 是旧数据（设置组 3 项，不含 agent-sessions）；编辑模式草稿只基于已存 order，
  新菜单项靠 resolveGroupItems 的 rest 补显示但**不在草稿数组** → 拖不动（from 索引越界）、保存不进 order
