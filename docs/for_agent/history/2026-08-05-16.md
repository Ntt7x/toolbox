# 2026-08-05-16 — 逆回购月度数据触发式更新（服务端自动，前端零改动）

**会话主题**：买断式逆回购月度数据支持触发式更新——检测到"上个月及更远"缺失时，
服务端自动触发 LLM 搜索补全；前端无需改造。

## 完成的功能

1. **触发式更新机制（服务端）**：
   - `missingMonths(rows)`：最新数据月 < 上个月 → 缺失月份列表（上个月含）；
     当月进行中不算缺失
   - `GET /tools/reverse-repo/monthly`：返回时自动检测 → 缺失则 createTask 后台执行
     `runMonthlyUpdate`（LLM 搜索补全），响应带 `stale/staleMonths`（前端可选展示，不影响现有渲染）
   - 防重：`reverseRepo:monthlyUpdate` KV 记 running，running 中不重复触发
   - `GET /monthly/update-status` 查进度；`POST /monthly/refresh` 手动触发（幂等）
2. **合并校验（幂等安全）**：LLM 返回月份必须 > 现有最大月 且 ∈ expected，
   否则跳过（防乱序/重复/污染）；无有效写入 → failed 且不动 KV
3. **prompts**：新增 `reverse-repo.monthly-update` 模板（{months} 占位符，搜索指定缺失月份）
4. **shared**：ReverseRepoMonthlyResponse 加 `stale/staleMonths`；
   新增 ReverseRepoMonthlyUpdateStatus 契约
5. **前端**：仅 api.ts 加两个可选方法（update-status / refresh），页面零改动
