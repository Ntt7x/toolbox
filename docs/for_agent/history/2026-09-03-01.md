# 2026-09-03-01 — watchlist 标签树重构 + 券商式 K 线 + 历史数据迁移清理

**会话主题**：在 `refactor/watchlist-tags` 分支完成自选股（watchlist）以「标签树（tag）」为核心的组织模型，
新增券商式 K 线图（无成交量副图），并修复历史「分组」模型残留键导致的数据治理告警。

## 一、核心改动

### 1. 标签树（tag）取代分组（group）为顶层组织
- 旧模型：`watchlist:group:<id>`（分组）+ 标的挂在分组下。
- 新模型：以 **tag** 为节点，支持树状层级（parent/children），标的不变量挂在 tag 上。
- 涉及文件：`features/watchlist/{store,service,logic,index,track}.ts`、`packages/shared/src/index.ts`（契约）。
- 前端：`WatchlistTool.tsx` + `tools/watchlist/{TagTree,ItemList,AlertsPanel,DeepDivePanel,LogicPanel,TrackPanel,KlineChart,ui}.tsx`（均为新增/大改）。

### 2. 券商式 K 线图（KlineChart.tsx，新增）
- 用 lightweight-charts 渲染日 K（OHLC），时间轴用 `BusinessDay`（`toBusinessDay`），**不含成交量副图**（按需求移除）。
- 数据源：`core/kline.ts` 腾讯日 K（qfq），已补 `volume` 字段解析（`[date,open,close,high,low,volume]`，index 5）。
- 接口：`GET /api/tools/watchlist/items/:code/kline`，返回 `KlineBar[]`（date/open/high/low/close/volume）。
- 验证：dev 实测 `sh600519` 返回 501 根日 K，OHLC 齐全，`force=1` 时含 volume（默认缓存可能返回旧格式，TTL 命中旧缓存属正常）。

### 3. 历史数据迁移清理（store.ts）
- `migrateLegacyGroups()` 升级旧 `watchlist:group:<id>` → tag 模型（幂等，已迁移跳过重建）。
- **修复**：升级后清理残留旧键（`watchlist:<groupId>`、`watchlist:alert:<id>`、`watchlist:alerthit:<id>`、`watchlist:logic:<id>:`、`watchlist:hotnews`），否则会变成「未标记数据源」违反数据治理。
- 新增 `cleanupLegacyGroupKeys(groups)`，在「已迁移但有残留」分支也调用，保证幂等清理。
