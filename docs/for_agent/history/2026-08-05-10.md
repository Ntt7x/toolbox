# 2026-08-05-10 — Chat 按钮改剪贴板中转（DeepSeek 网页版不支持 URL 预填）

**会话主题**：用户反馈跳转 DeepSeek 时未携带提示词作为输入——抓取 DeepSeek 网页版
JS 代码验证根因，修复并改为剪贴板中转方案（用户选择）。

## 根因（代码验证）

抓取 `chat.deepseek.com` 首页 JS（main.9674f322bd.js，1.3MB）分析：
- 仅解析 `?model=`（选择模型）与 `?redirect=`（OAuth 回调）两个 URL 参数；
- **没有任何输入预填逻辑**——`?q=` 参数无效是 DeepSeek 网页版实现使然。
- 另发现确定性 bug：`window.open` 在剪贴板异步回调（`.finally()`）里执行，
  丢失用户手势上下文 → 被浏览器**弹窗拦截**。

## 完成的功能

1. **修复弹窗拦截**：`window.open` 改为同步执行（在 onClick 手势内）；
   剪贴板复制改为异步 fire-and-forget（不再阻塞弹窗）。
2. **移除无效 `?q=` 拼接**：不再构造 `?q=` URL（已验证无效，保留反而误导）。
3. **剪贴板中转**：同步打开 `https://chat.deepseek.com/` + 自动复制提示词 +
   页面提示「已打开 DeepSeek 网页版并复制提示词；网页版不支持 URL 预填，
   请在输入框粘贴（Ctrl/Cmd+V）后发送」。
