# 2026-08-06 45 · 会话两级生命周期（活跃 30 天 / 归档 360 天 / 过期清理）

## 需求
用户确认：活跃期 30 天，归档期 360 天，过期 >360 天。（TTL 必要性分析：无界膨胀/语义过期/缓存与状态矛盾 → 两级生命周期）

## 实现
### chatSession.ts（模式 2）
- 常量：`ACTIVE_TTL_MS = 30d`、`ARCHIVE_TTL_MS = 360d`（替代原 90 天单 TTL）
- `archiveSessionInternal(s)`：进入归档期时把 history 折叠为 `summary`（最近 2 轮 verbatim + 早期折叠标记），history 清空，`archived=true`
- `restoreArchivedSession(id)`：归档续用时把 summary 注入为 `[历史摘要]` user 消息，archived=false，重新进入活跃期
- `loadSession`：>360d 删除；>30d 且未归档 → 自动归档
- `chatSessionAsk`：先 restoreArchivedSession（归档自动恢复续用）
- `listChatSessions`：触发归档标记 + 返回 status: active|archived；>360d 清理
- `ttlMs` 字段默认 ACTIVE（兼容）

### reasonix.ts（模式 3）
- `ACTIVE_MS = 30d`、`ARCHIVE_MS = 360d`（替代 REG_TTL_MS）
- `listReasonixSessions`：归档态（>30d 未用）自动 `session/close` 释放 reasonix 侧资源（fire-and-forget，注册表保留）；>360d 删注册表
- 归档续用：`reasonixAsk` 遇 unknown session → `session/resume`（从磁盘 transcript 恢复，不重放历史）重试 → 实测成功

## 验证（真实 key）
- chatSession：31 天后 list 显示 archived（历史折叠）；ask 自动恢复续用 ok → 恢复后 active；400 天后清理 ✓
- reasonix：归档 list 触发 close 不报错；归档续用 ask "刚才结果加 2"=4（resume 恢复上下文）✓
- typecheck 全绿
