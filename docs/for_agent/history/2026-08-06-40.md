# 2026-08-06 40 · 修复 LLM 用量按天聚合时区错位

## 问题
用户反馈"新的一天了，为什么 LLM 用量管理没有展示今天的数据？"

## 根因
`core/llm.ts` `getLlmUsageSummary` 按天切割用 `e.ts.slice(0, 10)`——取的是 ISO 字符串前 10 位 = **UTC 日期**。中国时区（UTC+8）凌晨的调用（如 8-06 00:06 北京 = 8-05 16:06 UTC）被记到 UTC 前一天 → 本地新的一天看不到当日数据。

## 修复
- 新增 `localDay(iso)`：用 `Date` 的本地时区 getter（服务器本地时区 = 用户机器时区）格式化 YYYY-MM-DD；无效日期兜底回字符串截断
- byDay 聚合改用 localDay

## 验证
- typecheck 全绿
- 服务器本地日期 2026-08-06（UTC+8）时，byDay 输出：`08-06 1次` + `08-05 6次`（此前 7 次全归 08-05）✓
