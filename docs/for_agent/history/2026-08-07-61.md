## 二、开发进程管理器（scripts/dev.mjs）

- 统一 `start|stop|restart|status|kill-port`；启动前清 8787/5173 残留（netstat→tasklist 确认 node→taskkill /T /F）；
  常驻 supervisor 每 5s 健康检查（进程退出**或端口空闲**都自动重启 ≤8 次，15s 宽限期）；
  stop 写 `.file/dev.stop` 标记防拉起；子进程日志 `.file/dev-logs/`。
- **实测**：强杀 server 后 15s 内自动恢复 health 200；stop 端口全清。
- dev.md §3.1 强制：禁止手动起 tsx watch/vite。
- **坑**：后台任务用 PowerShell 语法（`;` 非 `&`）；spawn 子进程不 unref（supervisor 需常驻监听 exit）。
