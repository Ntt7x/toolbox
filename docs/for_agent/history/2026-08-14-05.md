## 关键调研结论（影响决策）

1. **qiankun × Vite 6 不兼容**：官方 2.x 不支持 ESM（基于 import-html-entry+UMD）、
   3.0 仍 rc 未 stable、社区插件（vite-plugin-qiankun 已归档 / legacy 版停更）——
   且个人单机场景无微前端隔离价值 → **不引入**
2. **后端微服务不拆进程**：分享方案的 Spring Cloud/gRPC/Istio/网关/注册中心/消息队列
   均为多机分布式设计，单机单仓库用单进程 Hono + 已有 Cordis DI 替代

## 分期规划（触发条件满足时重启）

- Phase1 公共库抽象：packages/ui + packages/utils + packages/server-core（core/ 提升）
- Phase2 模块边界：React.lazy 懒加载 + /api/tools 动态菜单 + 模块开关
- Phase3 Cordis DI 规范化（todoV3 模式推广）
- Phase4 微前端评估（qiankun 3.0 stable / Module Federation）
