## 如何新增一篇

- 命名：`YYYY-MM-DD-NN.md`（NN 为当日序号，最大者最新）；内容：时间、会话主题、按序完成的功能（含文件/API）、git commit、**遗留/规划事项**（🔮 未实现 🚧 未提交）。
- 规则：只增不改（除非事实错误）；归档后必须同步更新 dev.md 常驻规范（dev.md §8.1）。
- 新会话结束时追加；本 INDEX 的「最新进展」与「主题索引」同步补行。
