## 教训
- **shared 大块删除的边界陷阱**：用 `indexOf('export interface TradeV2')` 作删除终点会误伤
  相邻的 Docs 类型（DocFolder 等）——先 `git checkout` 恢复，再按精确行号（找到
  TradePlan 块终点 = DocFolder 前 4 行）删除；误删后可用 git 恢复 + 重删
- **PowerShell 中 `>` 是重定向符**：node -e 字符串里 `'->'` 会被 cmd 拆解 → 报
  `Expected ','`——用中文或避免 `>` 字符
- 下线 feature 时：先确认下游依赖（v2 importV1 曾读 v1 数据），再确认用户意图
  （"数据已导入 v2" 才允许删数据）
