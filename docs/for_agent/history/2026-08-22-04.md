## 改动总结

### 1. 全部组合 = 一般组合（数据结构统一，mt52hjgp）
- **设计**：组合 = 一组标的 entries；统一入口 `analyzeGroup(group, entries, prices, klines) → TradeV2GroupAnalysis`——任何组合都走它
- **全部组合** = 合成组（无约束）+ 全部标的 entries → 同一个 `analyzeGroup` 输出（positions 跨组合天然合并、dailySeries 按日天然聚合）
- `TradeV2GlobalAnalysis.analysis` = `TradeV2GroupAnalysis`（与分组同一数据结构，零强转）
- 前端收益分析 tab 一套 JSX：`src = isGroupView ? analysis : global?.analysis`；4 个图表 option（donut/attr/月度/日度）数据源统一 `src`
- **组合分析 tab 单独承载组合逻辑**：组合整体卡 + 分组贡献/市值占比/盈亏对比/累计已实现曲线/净值曲线（overview 数据独立于组合本身）
- **DRY**：抽取公共 `enrichPositions()`（分组/全局共用行情附加逻辑，消除复制）

### 2. 交易量按金额统计（memo：统计对象是金额不是股数）
- 资金概览"交易量"卡：累计买入/卖出/净买入 = 金额（cny，从 dailySeries 汇总 buyAmount/sellAmount）
- 日度买卖量图：y 轴"金额"、tooltip 金额格式、series 数据 buyAmount/sellAmount

### 3. 图例全选/全不选（三轮失败后最终方案）
- **三轮失败沉淀**：① `chart.on("contextmenu")` echarts/zrender 不派发右键事件；② `mousedown` 只处理左键；③ zrender 元素 `getBoundingRect` 是局部坐标、legend 组件无区域 API
- **最终**：图表右上角「全选/全不选」按钮（zIndex 9999 + stopPropagation），手动逐个 `legendSelect/legendUnSelect` dispatch（`legendSelectAll/UnSelectAll` 实测无效）；点击图例项仍可切换单个系列
